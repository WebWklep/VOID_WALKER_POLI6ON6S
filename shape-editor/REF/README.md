# CREATURE LAB — material references

Загружай сюда референсы материала:
- общий вид материала без яркого света;
- тот же материал под направленным светом;
- крупные планы фактуры, пор, сколов и цветовых переходов;
- любые дополнительные примеры того, каким должен быть камень.

Лучше добавлять изображения в исходном качестве. В названии файла можно коротко указать, что именно важно: `base-color`, `sunlight`, `surface-detail` и т. п.

Эти файлы используются как визуальные ориентиры для настройки материала CREATURE LAB.
